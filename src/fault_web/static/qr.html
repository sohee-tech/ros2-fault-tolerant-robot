AMR-01 실시간 모니터

현재 네트워크

확인 중

⚠ 기기 간 통신이 막혀 있을 수 있는 네트워크입니다

학교·기업용 Wi-Fi(802.1X)에서는 휴대폰이 이 PC에 접속하지 못하는 경우가 많습니다. 아래 접속 진단에 기록이 남지 않으면 핫스팟을 사용하세요.

접속 진단

휴대폰 핫스팟으로 접속하기

  1. 휴대폰에서 핫스팟을 켭니다. 휴대폰 데이터가 사용됩니다.
  2. 이 PC의 Wi-Fi를 그 핫스팟에 연결합니다.
  3. 이 화면의 주소와 QR코드가 수 초 안에 자동으로 바뀝니다. 서버를 다시 실행할 필요가 없습니다.
  4. 그 휴대폰으로 새 QR코드를 스캔합니다.

다른 휴대폰도 같은 핫스팟에 연결하면 함께 접속할 수 있습니다.

접속이 안 될 때 확인

  1. 휴대폰이 LTE/5G가 아니라 위 네트워크와 같은 Wi-Fi에 연결되어 있는지
  2. QR 앱 내장 브라우저 대신 Chrome 또는 Safari에 주소를 직접 입력했는지
  3. 주소가 https가 아닌 http로 시작하는지
  4. 휴대폰의 VPN, 비공개 릴레이, 데이터 절약 모드가 꺼져 있는지
